# Backend App CLI

## Overview

`backend-app-cli` is a command-line application that sets up a JavaScript or TypeScript project template, avoiding the need to manually configure an MVC-based Node.js backend project.

## Features

- Quickly scaffold a new JavaScript or TypeScript project.
- Pre-configured MVC structure.
- Saves time and reduces setup errors.

## Installation

To install `backend-app-cli` globally, use the following command:

```bash
npm install -g backend-app-cli
```

## Usage

After installing the package globally, you can use the CLI to create a new project by running:

```bash
backend-template-cli
```

This command will prompt you with options to build either a JavaScript or TypeScript project. Follow the on-screen instructions to complete the setup.

## Example

1. Open your terminal.
2. Run the command:

    ```bash
    backend-template-cli
    ```

3. Select the project type (JavaScript or TypeScript) when prompted.
4. The CLI will generate the project template in your current directory.
